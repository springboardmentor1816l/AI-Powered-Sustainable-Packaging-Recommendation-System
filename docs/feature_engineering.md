# Feature Engineering

- Selected numerical and categorical features
- Encoded categorical variables using Label Encoding
- Scaled numerical features using StandardScaler
- Generated ML-ready datasets for modeling


## Techniques Used
- Label Encoding for categorical features
- Standard Scaling for numerical features

## Assumptions
- Higher suitability score indicates better packaging material
- All features contribute equally

## Scoring Strategy
Synthetic suitability score derived from feature averages.
