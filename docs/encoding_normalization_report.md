# Encoding and Normalization Report

## Overview
This report explains the encoding of categorical features and normalization of numeric features.

## Encoding
Categorical columns were converted into numerical format using One-Hot Encoding.
This makes the data suitable for machine learning models.

## Normalization
Numeric columns were scaled between 0 and 1 using MinMaxScaler.

## Saved Files
- Encoded dataset: materials_final_encoded.csv
- One-Hot Encoder: ohe_encoder.pkl
- Numeric Scaler: numeric_scaler.pkl
