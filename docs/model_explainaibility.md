# Model Explainability – EcoPackAI

## Cost Prediction Model
Top influencing features:
- Product weight
- Material type
- Cost per unit
- Recyclability percentage

The model assigns higher cost to heavier products and less recyclable materials.

## CO₂ Prediction Model
Top influencing features:
- CO₂ emission per kg
- Biodegradation time
- Recycled content percentage

Materials with higher recycled content and faster biodegradation show lower CO₂ impact.

## Observations
- Feature influence aligns with sustainability logic
- No target leakage observed
- Models behave consistently across products
