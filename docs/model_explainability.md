# Model Explainability – EcoPackAI

## Objective
To interpret and explain the predictions generated by the machine
learning models used in EcoPackAI.

## Explainability Technique
SHAP (SHapley Additive exPlanations) was used to understand feature
contributions.

## Global Explainability
- SHAP summary plot shows the overall impact of each feature
- Higher absolute SHAP values indicate stronger influence

## Key Observations
- Material strength and weight capacity strongly influence cost prediction
- Sustainability-related features also contribute significantly

## Conclusion
SHAP-based explainability ensures transparency and trust in model
predictions, making EcoPackAI suitable for real-world deployment.
