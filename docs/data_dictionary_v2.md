# EcoPackAI Data Dictionary – Version 2

## Engineered Features

### CII (Circular Impact Index)
- Type: Float
- Range: 0–100
- Description: Measures environmental sustainability of packaging material
- Derived: Yes

### CEI (Cost Efficiency Index)
- Type: Float
- Range: 0–100
- Description: Balances cost and durability
- Derived: Yes

### MSS (Material Suitability Score)
- Type: Float
- Range: 0–100
- Description: Indicates suitability for packaging requirements
- Derived: Yes

### Final_Recommendation_Score
- Type: Float
- Range: 0–100
- Description: Weighted final score for material recommendation
- Derived: Yes
