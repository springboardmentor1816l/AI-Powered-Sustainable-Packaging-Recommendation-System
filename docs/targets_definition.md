# Target Variables Definition – EcoPackAI

## Primary Target
### recommended_material
- Type: Categorical
- Description: Final recommended sustainable packaging material
- Examples: Cardboard, PLA, Recycled HDPE, Biodegradable Plastic
- Purpose: Core output of EcoPackAI recommendation system

## Secondary Target (Optional)
### sustainability_score
- Type: Numeric (0–100)
- Description: Aggregated sustainability score derived from
  CO₂ impact, biodegradability, and recyclability
- Purpose: Ranking and explainability

## Tertiary Target (Optional)
### cost_efficiency_category
- Type: Categorical
- Values: Low, Medium, High
- Description: Cost-based classification to support budget decisions
