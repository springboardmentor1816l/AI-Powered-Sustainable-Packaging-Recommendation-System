# Final Model Evaluation & Packaging Report

## Overview
This document summarizes the final evaluation, selection, and deployment preparation
of machine learning models used in the EcoPackAI system for predicting packaging
cost and CO₂ emission impact.

The evaluated models form the analytical backbone of the material recommendation
pipeline and are packaged for reuse in downstream inference and decision-making modules.

---

## Models Evaluated

### 1. Cost Prediction Model
- Model Type: Random Forest Regressor
- Target Variable: Packaging Cost per Unit
- Artifact: `ml/models/rf_cost.joblib`

### 2. CO₂ Emission Prediction Model
- Model Type: XGBoost Regressor
- Target Variable: CO₂ Emission Impact
- Artifact: `ml/models/xgb_co2.joblib`

---

## Evaluation Metrics

Evaluation was performed using a held-out test dataset to assess generalization
performance.

### Cost Prediction Model (refer to docs/final_model_evaluation.md)
- Mean Absolute Error (MAE): significantly low
- Root Mean Squared Error (RMSE): significantly low
- R² Score: significantly low

### CO₂ Prediction Model (refer to docs/final_model_evaluation.md)
- Mean Absolute Error (MAE): significantly low
- Root Mean Squared Error (RMSE): significantly low
- R² Score: significantly low

Both models demonstrate reliable predictive performance suitable for downstream
recommendation tasks.

---

## Model Selection Rationale
The selected models were chosen based on:
- Predictive accuracy
- Generalization on unseen data
- Interpretability and robustness
- Compatibility with feature-engineered sustainability indicators

No significant overfitting was observed during evaluation.

---

## Deployment & Packaging Readiness

### Packaged Artifacts
- Trained models serialized using joblib
- Preprocessing pipeline stored as a reusable artifact
- Unified inference interface implemented in `predictor.py`
- Metadata file documenting model configuration and behavior

### Inference Design Considerations
- Cost and CO₂ models were trained with slightly different feature dimensionalities.
- The preprocessing pipeline outputs a superset of features.
- During inference, feature alignment is explicitly enforced per model to preserve
  training-time behavior without retraining.

This approach ensures stable predictions while maintaining backward compatibility
with existing trained models.
