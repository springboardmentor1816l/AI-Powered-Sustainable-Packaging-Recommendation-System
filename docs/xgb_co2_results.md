# XGBoost CO₂ Emission Prediction – Results Summary

## Objective
Predict CO₂ emission impact associated with packaging materials using
product and material features.

## Model Used
- XGBoost Regressor

## Dataset
- Integrated material–product dataset
- 561,832 samples after integration

## Evaluation Metrics
- MAE: Low error indicating accurate predictions
- RMSE: Stable error distribution
- R²: High explanatory power

## Key Insight
Material-related features such as recyclability and strength were strong
contributors to CO₂ emission prediction.

## Conclusion
The trained XGBoost model effectively predicts CO₂ emissions and can be
used downstream for sustainability-aware packaging recommendations.
