EcoPackAI Data Dictionary

This document details the database schema, column definitions, data types, and constraints for the EcoPackAI project. It is based on the source datasets (material_dataset.csv, Product.xlsx) and the schema requirements defined in the task document.

1. Table: materials

Description: Stores attributes of various eco-friendly packaging materials used for analysis and recommendation.

Column Name

Data Type

Key

Description

Accepted Values / Example

material_id

INT

PK

Unique identifier for the packaging material.

1, 2, 101

material_type

VARCHAR(100)



The common name or classification of the material.

Recycled Paper, Bioplastic, Corrugated Fiberboard, Glassine

strength_mpa

FLOAT



Mechanical strength capacity measured in Megapascals (MPa).

45.7, 73.4

weight_capacity

FLOAT



The maximum load capability of the material in Kilograms (kg).

1.58, 11.53

biodegradability_percent

FLOAT



Percentage of the material that breaks down in a natural environment.

0.0 to 100.0 (e.g., 96.1)

co2_emission_score

FLOAT



Carbon footprint index associated with producing the material.

26.9, 8.9

recyclability_percent

FLOAT



Percentage indicating how easily the material can be processed for reuse.

0.0 to 100.0 (e.g., 69.8)

cost_per_kg

FLOAT



Cost of the material per kilogram (in standard currency, e.g., INR/USD).

44.7, 186.06

industry_use_case

VARCHAR(100)



The primary industry sector where this material is typically applicable.

Household, Pharmacy, Electronics, Apparel, Food

Key

The mode of transport used for shipping the product.

3. Table: recommendation_logs

Description: Tracks the history of packaging recommendations generated by the ML pipeline for specific products.

Column Name

Data Type

Key

Description

Accepted Values / Example

rec_id

SERIAL

PK

Unique auto-incrementing identifier for the recommendation log entry.

1, 2, 3...

product_id

INT

FK

Foreign key referencing the products table.

Valid product_id from products table.

recommended_material_id

INT

FK

Foreign key referencing the materials table.

Valid material_id from materials table.

cost_prediction

FLOAT



The predicted cost associated with using this material for this specific product.

12.50, 45.20

co2_prediction

FLOAT



The predicted CO2 impact for this specific product-material combination.

5.4, 12.1

material_rank

INT



The ranking of this material among recommended options (1 being the best match).

1, 2, 3

created_at

TIMESTAMP



Timestamp when the recommendation was generated.

YYYY-MM-DD HH:MM:SS (Default: CURRENT_TIMESTAMP)

Data Relationships (ERD Summary)

One-to-Many: A single product can have multiple entries in recommendation_logs (if recommendations are run multiple times or multiple options are provided).

One-to-Many: A single material can be referenced in multiple recommendation_logs.

Constraint: recommendation_logs.product_id must exist in products.product_id.

Constraint: recommendation_logs.recommended_material_id must exist in materials.material_id.
