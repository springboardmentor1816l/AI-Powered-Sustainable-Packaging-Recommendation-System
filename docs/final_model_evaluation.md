# Final Model Evaluation – EcoPackAI

## Models Used
- Random Forest Regressor (Cost)
- XGBoost Regressor (CO₂)

## Evaluation Metrics
Metrics evaluated using test dataset:
- MAE
- RMSE
- R²

## Results
Both models outperform baseline linear models.
Random Forest shows stable cost predictions.
XGBoost captures non-linear CO₂ relationships effectively.

Models are packaged with preprocessing pipeline and metadata.
