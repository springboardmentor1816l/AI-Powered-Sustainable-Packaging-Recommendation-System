# EcoPackAI System Architecture

EcoPackAI follows a full-stack AI architecture combining frontend, backend, machine learning, and analytics components.

## Components
- Frontend UI: Collects product inputs
- Flask API: Handles requests and responses
- AI Model Engine: Predicts cost and CO₂ footprint
- PostgreSQL Database: Stores materials and products
- BI Dashboard: Displays analytics and reports

## Workflow
User Input → Frontend → Flask API → ML Engine → Database  
Recommendations → Frontend UI & Dashboard
